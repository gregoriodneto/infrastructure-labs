# infrastructure-labs

Portfólio de laboratórios práticos de infraestrutura, DevOps e troubleshooting. Cada exercício simula um incidente para praticar diagnóstico e validação.

## Laboratórios Docker

| Laboratório | Cenário |
| --- | --- |
| [001 · Container inacessível pelo host](docker/001-container-unreachable/) | Uma API FastAPI está em execução, mas o host não recebe resposta HTTP. |
| [002 · Comunicação entre microsserviços](docker/002-interservice-communication/) | Um fluxo de consulta de pedidos retorna HTTP 503 em um ambiente com FastAPI, Fastify e PostgreSQL. |

Para começar, abra a pasta do laboratório escolhido e consulte os arquivos do exercício.
